4.3.1 IPv4地址概述

这一节进入网络层最基础的概念——IP 地址。它要回答三个问题：IPv4 地址到底是什么、由谁分配、长什么样。先把定义说准（32 比特、全球唯一、按接口分配），再说清编址方法走过的三个阶段，最后把点分十进制表示法和二进制—十进制换算练熟，因为后面分类编址、划分子网、无分类编址三节都要建立在这一节的表示方法之上。

1. IPv4 地址是什么

在 TCP/IP 体系中，IP 地址是一个最基本的概念，必须把它弄清楚。IPv4 地址就是给因特网（Internet）上的每一台主机（或路由器）的每一个接口，分配一个在全世界范围内唯一的 32 比特标识符。

这句话里有三个要点值得注意：

  • 32 比特——IPv4 地址的长度固定为 32 位二进制数，这正是它「地址空间有限」的根源；
  • 全世界范围内唯一——正因为唯一，IP 地址才能在网络层充当全局的寻址标识；
  • 分配给每一个接口——地址不是给「主机」这个整体，而是给主机（或路由器）的每个接口。一台路由器有多个接口，因此它拥有多个 IP 地址；这一点在后面理解路由器的转发过程时非常关键。

2. IP 地址的管理与分配

既然 IP 地址要求全球唯一，它的分配就不能由各网络随意进行。IP 地址由因特网名字和数字分配机构 ICANN（Internet Corporation for Assigned Names and Numbers）进行分配。我国用户可向亚太网络信息中心 APNIC（Asia Pacific Network Information Center）申请 IP 地址，并且需要缴费。

IPv4 地址的总量是有限的，早已分配出去：

  • 2011 年 2 月 3 日，互联网号码分配管理局 IANA（由 ICANN 行使职能）宣布，IPv4 地址已经分配完毕；
  • 我国在 2014 至 2015 年也逐步停止了向新用户和应用分配 IPv4 地址，同时全面开展商用部署 IPv6。

由此可见，IPv4 地址的紧缺不是将来才会发生的事，而是已经发生的事实。这也是后文要用子网划分、无分类编址把地址「用得更省」的原因。

3. 编址方法经历的三个历史阶段

IPv4 的编址方法并不是一开始就设计好的，它随着地址紧缺和网络规模膨胀而不断演进，经历了三个历史阶段：

  • 1981 年——分类编址：把地址空间分成 A、B、C 等几类，按类分配；
  • 1985 年——划分子网：在原有分类的基础上，把一个大网络再划分为若干子网，提高地址利用率；
  • 1993 年——无分类编址：不再按类划分，用「网络前缀 + 主机号」的方式灵活分配地址块。

这三个阶段是本章 4.3.2 至 4.3.4 三节的线索：4.3.2 讲分类编址，4.3.3 讲划分子网，4.3.4 讲无分类编址。三种方法中，后出现的并没有立刻取代前面的，而是长期共存、配合使用。

4. 点分十进制表示法

32 比特的 IPv4 地址不方便阅读、记录以及输入，因此 IPv4 地址采用点分十进制（dotted decimal notation）表示方法以方便用户使用。做法是：把 32 比特按每 8 位分为一组，共 4 组，写出每组对应的十进制数（不会超过 255），组与组之间用小数点隔开。

以原讲义给出的 32 比特地址为例：

32 比特 IPv4 地址：
00001010 11110000 00001111 10101010
每 8 位分为一组，写出各组的十进制数：
   10        240        15        170
写成点分十进制形式：10.240.15.170

下表是几个 32 比特地址与它们点分十进制形式的对照，可以当作练习检验自己是否已经掌握分组换算。

5. 8 位二进制数与十进制数的换算

点分十进制的书写与阅读都离不开 8 位二进制数与十进制数之间的相互换算，这是本章的基本功。

（1）8 位无符号二进制整数转十进制数

8 位二进制数的每一位都有自己的权值，从高位到低位依次是：

128   64   32   16   8   4   2   1

把每一位上的数字（0 或 1）乘以该位的权值，再全部相加，就得到对应的十进制数。例如：

  • 10101010 = 1×128 + 0×64 + 1×32 + 0×16 + 1×8 + 0×4 + 1×2 + 0×1 = 170；
  • 11111100 = 128 + 64 + 32 + 16 + 8 + 4 = 252，也可以看成 255 − 2 − 1；
  • 11110000 = 240，也可以看成 255 − 8 − 4 − 2 − 1；
  • 10000001 = 128 + 1 = 129。

全部为 1 的 11111111 对应 255，这也是点分十进制中每一组数字的最大值。熟悉的读者不妨记住几个常见的「整块」值（如 11110000 = 240、11000000 = 192、10000000 = 128），换算会快很多。

（2）十进制正整数转 8 位无符号二进制数

反过来有两种常用做法。第一种是除 2 取余法：把十进制数反复除以 2，记下每次的余数，直到商为 0，再把余数从下往上读出。例如把 130 转换为 8 位二进制数：

130 ÷ 2 = 65  余 0     ← 最低位
 65 ÷ 2 = 32  余 1
 32 ÷ 2 = 16  余 0
 16 ÷ 2 =  8  余 0
  8 ÷ 2 =  4  余 0
  4 ÷ 2 =  2  余 0
  2 ÷ 2 =  1  余 0
  1 ÷ 2 =  0  余 1     ← 最高位
从下往上读：130 = 10000010

第二种是凑值法：熟记 8 位二进制数各位的权值 128 64 32 16 8 4 2 1，从大到小试着凑出目标数，凑上的位置写 1，凑不上的写 0。例如 171：

171 = 1×128 + 0×64 + 1×32 + 0×16
    + 1×8 + 0×4 + 1×2 + 1×1
    = 128 + 32 + 8 + 2 + 1
    = 10101011

两种方法结果相同，实际换算时通常用凑值法更快，用除 2 取余法校核。

本节小结

  • IPv4 地址是给因特网上每台主机（或路由器）的每一个接口分配的、全世界唯一的 32 比特标识符。
  • 地址由 ICANN 分配，我国用户向 APNIC 申请且需缴费；2011 年 2 月 3 日 IANA 宣布 IPv4 地址分配完毕，我国自 2014—2015 年起逐步停止向新用户分配 IPv4 并转向 IPv6 商用部署。
  • IPv4 编址方法经历三个历史阶段：1981 年分类编址、1985 年划分子网、1993 年无分类编址，对应后面 4.3.2、4.3.3、4.3.4 三节。
  • 32 比特地址按每 8 位一组、写成 4 个十进制数并用小数点隔开，就是点分十进制表示法，每组数字的范围是 0～255。
  • 8 位二进制数与十进制数的换算靠各位权值 128 64 32 16 8 4 2 1：从二进制到十进制逐位加权求和，从十进制到二进制可用除 2 取余法或凑值法。
