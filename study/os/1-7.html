操作系统原理 · 第 1 章 绪论

1.7 UNIX系统

这一节把镜头对准第一个真正意义上的现代操作系统——UNIX。它的价值不只是一套代码：从 Multics 的失败中得出的设计教训，C 语言与可移植性的结合，以及 shell、树形目录、文件与设备统一处理这些沿用至今的做法，都是操作系统这门课绕不开的源头。

1. UNIX 是什么

一句话概括：UNIX 是一个交互式的、多用户的分时操作系统。这三个定语分别对应它的三种能力——用户能通过终端与系统会话（交互式），多个用户可以同时使用同一台机器（多用户），而这些用户是靠时间片轮转共享处理机的（分时）。上一节讲 MULTICS 时提到的分时处理、远程联机、文件系统、多级反馈调度等概念雏形，在 UNIX 这里变成了可用、可移植、可传播的现实。

2. 从 Multics 到 UNIX

（1）Multics：宏大的目标与失败的教训

故事从 1965 年开始。麻省理工大学、BELL 实验室和通用电器公司组成 MAC 课题组，联合研制 Multics 操作系统，设计目标是：向大的用户团体提供对计算机的同时访问，支持强大的计算能力与数据存储，并且允许用户在需要的时候容易地共享他们的数据。

1969 年 Multics 在 GE645 计算机上运行了，但结果并不理想：它既没有能提供预定的综合计算服务，甚至连项目组自己也不清楚究竟什么时候才算达到开发目标。BELL 实验室退出了该课题组。

课件把失败的原因归结到当时操作系统设计的指导思想上——「满足所有用户的所有要求」。目标定得越全，系统就越复杂，越难以实现和交付；这也从反面提示了后面几章反复出现的主题：操作系统的设计本质上是在诸多目标之间做取舍。

（2）UNIX 的诞生

UNIX 的作者给出的判断与 Multics 相反：操作系统的设计不应也不可能做到「满足所有用户的所有要求」，而应为广大的计算机用户提供一种良好的程序设计环境。

1969 年，K. Thompson 和 D. Ritchie 为了改善自己的程序设计环境，设计了一个纸面的文件系统方案，这个设计后来演化成 UNIX 系统的早期版本，并在 PDP-11 计算机上实现。随后 D. Ritchie 创造了 C 语言，并用 C 语言改写了早期的 UNIX 系统——这一步的意义极大：用高级语言写操作系统，使它易读、易懂、易修改，也第一次让操作系统具备了良好的可移植性。1974 年，他们在《ACM 通信》上发表了论文《The UNIX Time-Sharing System》，UNIX 正式公布于世。

3. UNIX 的传播与流派

由于 UNIX 生逢其时、品质优秀，很快风靡全球，成为各种计算机系统的主流操作系统，并在传播中分化出多个流派。课件把它分为三大类：

  • BSD UNIX；
  • AT&T UNIX SVR 4.X（System V Release 4）；
  • SCO UNIX。

各厂商也在自己的硬件平台上发布了各自的 UNIX 版本：惠普计算机上的 HP-UX、IBM 小型机上的 AIX、苹果 Mac 上的 AUX、SUN 工作站的 Solaris。

注记：苹果那一支通常写作 A/UX；今天的 macOS 同样基于 UNIX 血统（Darwin 内核），而 Linux 则是遵循 UNIX 设计思想、但独立实现的类 UNIX 系统，本课程后面的章节会以 Linux 为主要实例。

4. UNIX 操作系统的主要特点

UNIX 之所以能长期占据主流地位，靠的是几条一以贯之的设计特点：

  • 用 C 语言编写：易读、易懂、易修改，也容易移植到别的计算机上；
  • 简单的用户界面——shell：用户通过 shell 输入命令、组织命令，与系统交互；
  • 树形目录结构组织文件系统：层次清晰，便于分类管理大量文件；
  • 文件与设备统一处理：把外部设备也当作文件来对待，用户可以用同一套操作去读写文件或操作设备，这正体现了 1.4 节所说的「屏蔽硬件差别、提供一致的接口」；
  • 多任务、分时系统：多个任务并发推进，多个用户共享机器；
  • 虚拟内存：在有限的主存上提供更大的编程空间。

这六条恰好把第 1 章讲过的几个关键词都落到了实处：一致的用户接口、并发、虚拟技术、文件管理。第 9 章 9.8 节还会专门剖析 UNIX 文件系统的主要结构与实现。

本节小结

  • UNIX 是一个交互式的多用户分时操作系统；
  • 前史是 1965 年 MIT、BELL、GE 组成 MAC 课题组研制的 Multics：目标是为大用户团体提供同时访问、强大计算与存储能力以及方便的数据共享；1969 年在 GE645 上运行，但未达预定目标、开发进度失控，BELL 退出；失败根源是「满足所有用户的所有要求」这一设计指导思想；
  • UNIX 的作者主张操作系统应为用户提供良好的程序设计环境。1969 年 K. Thompson 与 D. Ritchie 从纸面的文件系统设计出发，做出 UNIX 早期版本并在 PDP-11 上实现；D. Ritchie 创造 C 语言并重写 UNIX；1974 年论文《The UNIX Time-Sharing System》发表于《ACM 通信》，UNIX 正式公布；
  • UNIX 传播中形成 BSD UNIX、AT&T UNIX SVR 4.X、SCO UNIX 三大分类，以及 HP-UX、AIX、A/UX、Solaris 等厂商版本；
  • UNIX 的主要特点：用 C 语言编写（易读易改易移植）、shell 用户界面、树形目录结构的文件系统、文件与设备统一处理、多任务分时、虚拟内存。
