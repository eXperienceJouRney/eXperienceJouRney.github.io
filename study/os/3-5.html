操作系统原理 · 第 3 章 用户接口

3.5 小结

这一章讲的是用户接口。把这一章收拢起来只有五个问题：应用程序是怎么一步步变成可运行程序的、两种连接方式差别在哪、操作系统对外提供哪两个接口、真实系统的用户界面长什么样、系统调用到底是什么并如何实现。下面按这五条线索把全章要点串一遍。

1. 处理应用程序的步骤及各步骤之间的关系

一个应用程序从源程序到得出计算结果，走的是「编译 → 连接 → 运行」这条链，对应的三个时段是编译时间、连接装配时间、运行时间。编译阶段由编译器或汇编器把源程序变成目标模块；连接阶段由连接装配程序把主程序和其他所需要的子程序、例行程序连接装配在一起，形成可执行的、完整的主存映像文件；运行阶段把主存映像文件调入主存、启动运行，得出计算结果。三个步骤之间的关系是严格的前后依赖：没有目标模块就无从连接，没有可执行的主存映像文件就无从运行。以 C 程序为例，这条链在命令上表现为 hello.c → hello.i → hello.s → hello.o → hello。

2. 静态连接与动态连接的区别

  • 静态连接：把所有外部调用的函数都连接到目标文件中，形成一个完整的可执行文件，运行时不再需要其他的链接库。缺点是多个应用程序若调用同一个库中的外部函数，每个目标文件里都会包含一份该函数的代码，空间重复。
  • 动态连接：不需要把外部函数链接到目标文件中，而是在应用程序中需要调用外部函数的地方作记录并说明函数名，运行时才加载依赖的动态链接库。多个程序因此可以共享同一份库代码，代价是运行时多一次装入。

3. 操作系统提供的两个接口及使用场合

任何操作系统都必须同时提供两个接口：

  • 操作接口（命令接口）：用户使用它来组织工作流程、控制程序的运行。它又分作业控制语言、键盘命令、图形界面三种形态，分别对应脱机批处理操作系统，联机分时与个人计算机操作系统，以及个人计算机操作系统；
  • 程序接口（系统功能调用）：用户程序在运行过程中用它来请求操作系统的服务。

简单说，面向人的场合用操作接口，面向程序的场合用程序接口，两者缺一不可。

4. 实际操作系统的用户界面举例

  • 作业控制语言：脱机批处理系统提供 JCL，一个作业由作业申请（作业名、需用 CPU 时间、最迟完成时间、资源请求等）、操作说明书（编辑、编译、连接、运行命令）和程序与数据三部分组成，IBM 系列机器上的 JCL 以 // 开头逐行书写；
  • 键盘命令：为联机用户提供，直接控制和干预程序运行。DOS 把命令分为文件管理（COPY、COMP、TYPE、DEL、REN）、磁盘管理（FORMAT、CHKDSK、DISKCOPY、DISKCOMP）、目录管理（DIR、CD、MD、RD、TREE）、日期时间与系统设置（DATE、TIME、VER、VOL）以及应用程序（MASM、LINK、DEBUG）几类；UNIX 也提供命令行界面；
  • 图形用户界面：集成菜单驱动、图符驱动与面向对象技术，所有程序以统一的窗口形式出现、提供统一的菜单格式、以图标表示系统资源与命令、操作方法统一。代表性产品是 Microsoft Windows（1984 年 Macintosh，1986 年 X Window System，1992 年 Windows 3.1）。

5. 系统调用的概念与实现方法

系统调用是用户在程序一级请求操作系统服务的一种手段，它不是一条简单的函数调用硬件指令，而是带有一定功能号的「访管指令」；功能并非由硬件直接提供，而是由操作系统中的一段程序完成的，即由软件方法实现。它是操作系统提供给编程人员的唯一接口。

实现方法上，各家具体的做法不同，实质却一致：硬件提供访管指令（访管中断）svc i；每个系统调用对应一个系统调用号、一个执行程序段，并要求一定数量的输入参数和返回值。执行时保护现场、取出功能号 i、按 i 值转移，通过入口地址表进入相应的例行子程序，返回前恢复现场。由此也要分清两点区别：系统调用是软件实现、在核心态运行，访管指令是硬件中断指令、是进入核心态的通道；系统调用的代码属于操作系统并会引起用户态到核心态的切换，而库函数由其他软件提供、链接进用户程序，执行时不改变处理机状态。为便于程序跨系统移植，系统调用接口有国际标准 POSIX（IEEE 1003／ISO/IEC 9945），Linux 完全兼容 POSIX。

本节小结

  • 处理应用程序＝编译（得到目标模块）＋连接（装配成主存映像文件）＋运行（调入主存求解），三个步骤前后依赖，对应编译时间、连接装配时间、运行时间。
  • 静态连接把外部函数并入目标文件、运行时不再需要链接库但代码重复；动态连接只记录函数名、运行时加载动态链接库，库代码可被多个程序共享。
  • 操作系统必须同时提供操作接口（命令接口）和程序接口（系统功能调用）：前者用于组织工作流程、控制程序运行，后者供用户程序请求操作系统服务。
  • 命令接口的三种形态各有实例：JCL 用于脱机批处理，键盘命令（DOS、UNIX）用于联机交互，图形用户界面（Windows、UNIX 桌面）用于个人计算机。
  • 系统调用是带功能号的访管指令、由软件实现、在核心态运行，是操作系统提供给编程人员的唯一接口；它封装成高级语言函数后与库函数写法相同，但代码归属和执行时的处理机状态都不同。
